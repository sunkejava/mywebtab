# 测试计划

1. 验证 8 个默认基金的代码、类型和名称。
2. 验证基金与沪深股票代码转换为腾讯行情符号。
3. 验证基金、股票行情文本转换为统一价格/涨跌结构，无效内容抛出明确错误。
4. 验证 Edge 收藏夹文件的嵌套目录、HTML 实体、分类推断、危险协议过滤。
5. 验证导入时 URL 去重且保留已有快捷方式。
6. 运行新增测试，再运行完整 `npm run check` 与打包校验。
7. 验证同名嵌套目录按完整路径生成不同、稳定的分类 ID，并提取动态分类元数据。
8. 验证批量删除同时删除多个选中 ID、空选择不改变数据，且清理不再使用的导入分类。
9. 静态验证管理弹窗的全选、批量删除和关闭入口已经接入，避免逐项删除时递归重建弹窗。
