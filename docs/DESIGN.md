# 页面设计说明

## 设计原则

页面使用“时间与搜索优先、导航次之、小组件补充”的三级信息结构。默认首屏不展示复杂配置入口，仅在右上角保留专注模式和设置按钮。

## 页面结构

1. 顶栏：产品标识、专注模式、个性化设置。
2. 主视觉：大号时钟、完整日期、搜索引擎与搜索输入框。
3. 导航板：分类标签、网站快捷方式、当前分类管理入口。
4. 小组件：天气、日历与每日短句。
5. 设置弹窗：主题、本地背景、显示效果与配置数据管理。
6. 工具箱：独立双栏工作台，避免开发工具挤占新标签页首页空间。

## 视觉规范

- 半透明深色卡片覆盖在主题或用户背景上，使用可调模糊保证不同背景下的可读性。
- 青绿色为主强调色，危险操作单独使用红色语义。
- 圆角按 11 / 17 / 22 / 24px 分级，避免无规律使用。
- 桌面端快捷方式最多九列；中屏六列；窄屏四列，小组件同步降为单列。

## 交互约定

- `/` 聚焦搜索框，`Esc` 关闭弹窗或引擎列表。
- 输入普通文本执行当前引擎搜索；输入域名或完整 URL 直接访问。
- 天气卡片整体可点击，首次点击请求浏览器定位授权。
- 所有会改变页面状态的操作立即写入浏览器本地存储。
