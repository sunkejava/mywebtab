# MyWebTab 产品规划

## 产品定位

MyWebTab 是一个面向 Edge 与 Chrome 的本地优先新标签页：打开速度快、默认内容开箱即用，同时允许用户按自己的工作与生活场景进行调整。

## 首版范围

| 模块 | 首版能力 |
| --- | --- |
| 搜索 | 必应默认；Google、百度、DuckDuckGo、搜狗、360、Yandex、Brave 及 GitHub、B站、知乎、YouTube、npm、MDN 等垂直搜索 |
| 分板 | 常用、开发、设计、AI、影音、办公；一键切换并记忆当前板块 |
| 快捷方式 | 内置常见站点；自定义名称、地址、图标文字、颜色与板块；删除及恢复默认 |
| 个性化 | 4 套渐变主题、本地背景图片、卡片模糊度、背景遮罩、专注模式 |
| 小组件 | 实时时钟、日期、日历、每日短句、基于当前位置的实时天气 |
| 数据 | 浏览器本地持久化；JSON 导入与导出；不依赖账号和后端 |

## 非功能目标

- Manifest V3，兼容当前 Chromium 内核的 Edge 与 Chrome。
- 不加载远程 JavaScript，不使用统计 SDK。
- 响应式布局，支持常见桌面宽度及窄屏窗口。
- 无前端框架和运行时依赖，减少包体积与供应链风险。

## 后续方向

- 快捷方式拖拽排序、自定义分板、书签导入。
- 待办事项、番茄钟、RSS、纪念日等可插拔组件。
- Chrome Sync 可选同步及多设备冲突处理。
- 国际化、键盘导航增强、商店发布素材与隐私政策。
