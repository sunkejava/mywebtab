# MyWebTab

一个适配 Microsoft Edge 与 Google Chrome 的高颜值新标签页与开发工具箱。综合 iTab 的组件化体验和 uTab 的分组、壁纸与主题能力，坚持本地优先、无广告和开箱即用。

## 功能

- 14 个综合及垂直搜索引擎，可在搜索框左侧即时切换
- 常用、开发、设计、AI、影音、办公六个默认板块
- 网站真实 favicon 自动识别，缺失时回退到网站名称图标
- 可配置网站在新标签页或当前页打开，默认新标签页
- 四套主题、24张内置壁纸，以及中国大陆可直连的 360 分类壁纸、必应中国壁纸源
- 支持按风景、动漫、明星、城市等关键词在线搜索壁纸并一键设为背景
- 实时时钟、日期日历、每次打开随机谚语和自动刷新天气
- JSON、AES-GCM、RC4、Base64、SHA、MD5、GUID、时间戳工具
- 前端格式化/压缩/混淆、正则、Diff、编码、二维码、Cron、色彩、命令查询
- 博客分类以及国内外常见技术博客、开发者社区快捷方式
- 时间戳秒/毫秒自动识别、18个全球时区及相对北京时间差异
- 108条Linux、PowerShell、CMD核心命令离线查询
- 专注模式、配置导入导出、响应式布局
- 所有用户配置仅保存在浏览器本地

详细规划见 [产品规划](docs/PRODUCT_PLAN.md)，页面规范见 [设计说明](docs/DESIGN.md)。

## 安装

### Edge

1. 打开 `edge://extensions/`。
2. 开启左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目根目录。
4. 新建标签页即可使用。

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目根目录。
4. 新建标签页即可使用。

> 天气优先使用浏览器定位；拒绝时自动使用 IP 粗略定位。任何定位失败都会回退到上一次成功结果，不影响其他功能。

## 工具箱

点击首页右上角“工具箱”即可使用。HTTP 调试支持常见请求方法、自定义请求头和请求体；首次访问某个 API 域名时，浏览器会单独请求该域名的临时授权，不会在安装时永久读取所有网站。MQTT 测试使用 MQTT 3.1.1 over WebSocket，Broker 必须提供 `ws://` 或 `wss://` 端点。

MD5 是不可逆摘要算法，不存在可靠的“解密”。工具箱提供 MD5 生成和已知原文比对功能。

AES-GCM 使用 Web Crypto API 和 PBKDF2 密钥派生；RC4 仅用于兼容旧系统。DES、RC4、MD5 已不适合保护新系统中的敏感数据，其中 DES 不提供误导性的“安全加密”入口。

二维码生成使用 QRServer 免费接口；二维码图片优先在浏览器本地识别，在当前浏览器不支持 `BarcodeDetector` 时才上传到 QRServer 在线识别。

## 开发与打包

项目使用原生 HTML、CSS 与 ES Modules，无需安装依赖。

```bash
npm run check
npm run package
```

打包产物位于 `dist/mywebtab-v2.3.0.zip`。开发后在扩展管理页点击“重新加载”即可查看修改。

## 隐私

MyWebTab 不收集或上传用户数据。背景图片、快捷方式和设置保存在浏览器本地；天气功能仅在用户主动授权后将经纬度发送给 Open-Meteo 以获取天气数据。
